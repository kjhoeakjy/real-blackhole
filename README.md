# 우주 여행 · 지구로 돌아가기

지금 이 순간의 실제 우주 어딘가에서 눈을 뜨고, 사건이 하나씩 닥칠 때마다 선택하며 지구로 돌아오는 1인칭 게임. 출발지는 고를 수 없고 결과는 계산된 확률대로 한 번 굴린다 ("80억 분의 1" 같은 무작위 인생 게임의 우주 여행 판). 모든 거리·속도·위험은 측정값과 공식 문서의 숫자를 쓴다.

https://kjhoeakjy.github.io/real-blackhole/

## 흐름
1. **눈 뜨기** — 출발지 37곳 중 하나가 무작위로 정해진다: 달·행성(지금 위치, VSOP87), 가까운 별·외계행성(Gaia 시차), 블랙홀 곁(각 논문의 질량·거리), 다른 은하.
2. **출발 준비** — 블랙홀 곁이면 출발 거리(광선추적 화면), 그다음 탈것 3개 중 하나: 보이저 급(17 km/s), 파커 급(191 km/s), 빛의 20 %(가상).
3. **사건 카드** — 1인칭 조종석 화면에서 사건마다 선택한다. 선택지마다 **힌트** 버튼이 있고, 앞의 선택(동료 수·식량 방식)이 뒤의 사건과 선택지를 바꾼다.
   - 출발 전: 동료(혼자/셋/여섯), 벽(물탱크 차폐), 식량(저장/재배/배급), 물(재활용/전부 싣기), 전력(태양전지/RTG/소형 원자로)
   - 가는 길: 미소유성체, 연기 경보(1997 미르 화재), 산소 발생기 고장, 의료 사건(NASA IMM 0.06회/인·년), 동료 갈등 또는 고립(Mars-500), 태양 폭풍(1972년 8월급), 소행성대, 목성 방사선대·중력 도움, 성간 먼지(Hoang 2017), 뼈 손실, 귀환 통로(아폴로 ±1°), 재진입(1/180)
4. **결과** — 확률은 보여주지 않고 결과만 보여준다: "생존했습니다" 또는 "지구에 도착하지 못했습니다"와 원인. 확률은 접힌 "왜 이런 결과가 나왔나요"에만 있다.

무사 귀환 확률 = 수명(Gompertz) × 피폭(RAD 1.84 mSv/일, ICRP 5.5 %/Sv) × 블랙홀 탈출(조석 한계) × 가는 길의 선택 × 재진입. 결과 굴리기는 요인마다 일어나는 순서대로 한 번씩이라 곱하면 같은 확률이 된다. 통계가 없어 "모형"이라 적은 수치는 힌트에 그렇게 밝힌다.

## 구조 (빌드 없음, 정적)
```
index.html, src/app.js        진입점, 지도 ↔ 블랙홀 화면, 렌더 루프
src/ui/trip-mode.js           눈 뜨기 → 사건 카드 → 결과, 1인칭 카메라·조종석 HUD
src/data/destinations.js      출발지·탈것
src/data/hazards.js           사건·선택지·힌트 (출처 포함, 앞 선택에 따라 달라짐)
src/physics/trip.js           시간·시간 지연·피폭·수명·블랙홀·재진입 → 확률
src/physics/gr.js, disk.js    커 블랙홀 지평선·조석장, 강착원반 온도
src/scene/map.js              태양계(실시간) → 은하(Reid 2019) → 외부 우주 지도, 별하늘, 1인칭 모드
src/scene/bh-*.js             WebGL2 커 블랙홀 광선추적
data/blackholes.json          블랙홀 카탈로그 27개 (research/ 에 출처)
```
