# 외계인에게 납치됐다 · 지구로 돌아가기

지금 이 순간의 실제 우주 어딘가에서 눈을 뜨고, 사건이 하나씩 닥칠 때마다 선택하며 지구로 돌아오는 1인칭 게임. 출발지는 고를 수 없고 결과는 계산된 확률대로 한 번 굴린다 ("80억 분의 1" 같은 무작위 인생 게임의 우주 여행 판). 모든 거리·속도·위험은 측정값과 공식 문서의 숫자를 쓴다.

https://kjhoeakjy.github.io/real-blackhole/

## 흐름
0. **프롤로그** — 납치됐다가 낯선 곳에 버려진다. 그들은 떠났고 우주선 한 척과 식량만 남았다. 나이를 적고 눈을 뜬다.
1. **현재 위치** — 출발지 70여 곳 중 하나가 무작위로 정해진다: 달·행성·위성(지금 위치, VSOP87), 보이저·뉴허라이즌스 곁, 가까운 별과 외계행성 40여 곳(Gaia 시차), 성운, 블랙홀 곁(각 논문), 다른 은하.
2. **격납고** — 배 셋 중 하나. 화학 로켓 캡슐(17 km/s, 혼자, 태양 전지판), 핵전기 추진선(191 km/s, 4명, 동위원소 전지, 물탱크 벽), 광자 돛 항성선(빛의 20 %, 6명, 채소 재배·원자로·동면, 가상). 블랙홀 곁이면 출발 거리부터(광선추적 화면).
3. **항해** — 배 안의 시간이 실제로 흐른다 (한 항해 또는 한 인생이 약 2분, 속도 1×/3×/10×, 자동 결정). 나이를 먹고, 식량·물·산소·전력·선체·몸·마음·피폭 계기판이 움직이고, 사건이 끼어들면 시간이 멈추고 선택한다. 선택지마다 힌트, 결과는 숨겨진 확률로 정해져 한 문장으로 돌아온다. 1인칭 창밖은 실제 별하늘과 행성.
4. **끝** — 지구에 닿으면 하늘이 열리고, 중간에 죽으면 "인생 요약": 나이, 남은 거리, 사인, 받은 방사선, 겪은 사건, 지나온 길 전체.

### 사건
- **실제 기록 23종**: 1972년급 태양 폭풍, 1997년 미르 화재, ISS 산소·물 장치 고장, NASA 의료 모형(0.06회/인·년), Mars-500 갈등·고립, 보이저 비트 뒤집힘, 미소유성체, 전력 부족(보이저 RTG·주노), 항로 보정, 소행성대, 목성 통과, 성간 먼지(Hoang 2017), 뼈 손실, Wow! 신호, 아폴로 "반딧불", 가족 소식, 작물 곰팡이, 재진입(1/180).
- **SF 시나리오 26종** (src 에 "시나리오"라고 표시): 동면과 오작동, 항법 AI의 거부, 오래된 조난 신호, 레이더의 거대 물체, 떠돌이 블랙홀, 정체 모를 병, 무인 보급선, 파편 구름, 반란, 사랑과 출산, 환각, 배급, 정전, 우주 유영, 부고, 혜성, 떠돌이 행성, 지구의 침묵, 창의 금, 곰팡이, 소포, 감마선 폭발, 우리 배와 똑같은 신호, 노년.

### 매 순간 굴리는 것
수명(Gompertz, 기대수명 81세), 우주 방사선 1.84 mSv/일 × 차폐(물 벽 0.65) → 암 5.5 %/Sv 가 5–20년 뒤에, 급성 피폭(2 Sv 증후군, 4 Sv 반수 치사), 식량 1.83 kg/인·일, 물 회수 98 %, 산소 발생기, 햇빛 1/r², 플루토늄 반감기 87.7년, 사기가 낮으면 사건이 는다. 동면은 시나리오(소모 1/10, 몸의 시계 느리게).

## 구조 (빌드 없음, 정적)
```
index.html, src/app.js        진입점, 지도 ↔ 블랙홀 화면, 렌더 루프
src/ui/trip-mode.js           현재 위치 → 격납고 → 항해 화면(계기판·카드·속도·자동) → 도착/인생 요약
src/sim/voyage.js             항해 시뮬레이션 (시간·보급·피폭·수명·사건 추첨)
src/data/events.js            사건 49종: 제목·설명·선택지·힌트·숨겨진 결과 (출처 또는 '시나리오')
src/data/destinations.js      출발지 70여 곳·탈것 3종
src/physics/trip.js           피폭·수명·블랙홀 조석 상수
src/physics/gr.js, disk.js    커 블랙홀 지평선·조석장, 강착원반 온도
src/scene/map.js              태양계(실시간) → 은하(Reid 2019) → 외부 우주 지도, 별하늘, 1인칭 모드
src/scene/surface.js          버려진 곳의 풍경 (캔버스 2D: 행성·위성·별·성운·은하·탐사선, 그들의 배와 내 캡슐)
src/scene/bh-*.js             WebGL2 커 블랙홀 광선추적
data/blackholes.json          블랙홀 카탈로그 27개 (research/ 에 출처)
```
